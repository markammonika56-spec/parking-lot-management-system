# 🚗 ParkEase – Parking Lot Management System

A responsive web-based Parking Lot Management System developed using **HTML, CSS, and JavaScript**.

ParkEase helps manage parking slots, vehicle entries, exits, and parking fees through a simple and user-friendly interface.

---

## 📌 Project Overview

ParkEase is a BCA mini project designed to digitally manage a parking area.

The system allows users to:

- View available and occupied parking slots
- Add vehicle entry details
- Assign parking slots
- Search parked vehicles
- Track entry time
- Calculate parking fees
- Remove vehicles when they exit
- Store parking data using browser LocalStorage

---

## ✨ Features

### 🅿️ Parking Management
- 12 parking slots
- Real-time Available/Occupied status
- Easy slot assignment

### 🚘 Vehicle Management
- Vehicle number
- Owner name
- Vehicle type
- Entry time
- Vehicle exit management

### 🔍 Search System
Search vehicles using:
- Vehicle number
- Owner name

### 💰 Parking Fee
Automatic fee calculation based on:
- Vehicle type
- Parking duration

### 💾 Data Storage
Parking records are stored using **Browser LocalStorage**, so data remains available after refreshing the page.

### 📱 Responsive Design
The interface works on:
- 📱 Mobile
- 💻 Desktop
- 📟 Tablet
